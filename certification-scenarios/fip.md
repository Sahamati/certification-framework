FI Schema Test Plans for AA Ecosystem - FIP Test Plans v2.1.0

# Introduction to the FI Schema Test Plan

This test plan is designed to validate the compliance of FI schemas with ReBIT's guidelines and ensure consistency across different FI Types. The test cases are **FI-Type Agnostic**, meaning they can be applied across all FI Schemas — reducing duplication and ensuring consistency throughout the certification process.

Certifiers must ensure that the appropriate FI schemas are validated along with the FIP APIs certification. The test cases are structured to cover the active FI Types as per the FIP’s license category, and all active FI Types under each license must be certified.

---

## Instruction on Certification for FI Schema

To certify an FIP, certifiers must ensure that the applicable FI Schema is verified in conjunction with the FIP APIs certification (refer to the certification framework here).

**Active FI Types**:  
Certifiers must verify all FI Types relevant to the FIP’s license bracket given below. For each applicable FI Type, certifiers should ensure that the correct schemas are followed and validated according to the rules established by ReBIT. The certification process must cover all active FI Types under each license category.

**Proposed FI Types**:  
Some FI Types, including `CP`, `GOVT_SECURITIES`, `BONDS`, `DEBENTURES`, and `OTHER`, are in proposed status and are not yet available for certification.

**Withdrawn FI Types**:  
The `INSURANCE_POLICIES` FI Type has been withdrawn and should not be certified starting from **15th April 2025**. Please ensure that this FI Type is excluded from the certification process.
